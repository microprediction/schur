Theory

The idea explained, the constructions sorted, and the far end shown to be general.

  • An introduction
    The shared object, one dial with three readings, the closed-form reliability γ*, the family of bridges, what is proved about where to sit, and what the partition costs.
  • Which Schur is which
    Every bridge named by its endpoints, with the path, the split rule and the encoding that make each end exact or leave it approximate.
  • Minimum variance in disguise
    Every symmetric linear system has a financial reading, so maximum diversification, tangency, Kelly, decorrelation, forecast combination, hedging and GLS are all the same far end, and every bridge reaches them.

The proofs are in the papers; the demos recompute the conditions live.
